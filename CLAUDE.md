## Project Overview

Swiftfin is a SwiftUI video client for Jellyfin media server, targeting iOS 16+ and tvOS 17+. It uses VLCKit for broad codec support and native AVKit as an alternative player. The codebase is split into shared backend logic and platform-specific views.

## Build & Dependencies

```sh
# Install tools (first time)
brew install carthage swiftformat swiftgen

# Install/update Carthage dependencies (VLCKit)
carthage update --use-xcframeworks

# Build iOS
xcodebuild -scheme "Swiftfin" -destination "platform=iOS Simulator,name=iPhone 16,OS=18.5" build

# Build tvOS
xcodebuild -scheme "Swiftfin tvOS" -destination "platform=tvOS Simulator,name=Apple TV,OS=18.5" build

# Lint
swiftformat .

# Generate localized strings
swiftgen
```

SPM handles most dependencies (resolved by Xcode). Carthage handles only VLCKit (`Cartfile`).

Set your dev team in `XcodeConfig/DevelopmentTeam.xcconfig` (gitignored):

```
DEVELOPMENT_TEAM = "YOUR_TEAM_ID"
PRODUCT_BUNDLE_IDENTIFIER = org.jellyfin.swiftfin
```

## Architecture

- **`Shared/`** — All cross-platform code (iOS + tvOS share this)
  - `Services/` — Business logic, networking, download management, user session, keychain
  - `ViewModels/` — Stateful logic for views (MVVM pattern)
  - `Coordinators/` — Navigation via custom coordinator pattern (`NavigationCoordinator`, `TabCoordinator`)
  - `Components/` — Reusable SwiftUI components
  - `Extensions/` — Swift/SwiftUI/JellyfinAPI extensions
  - `SwiftfinStore/` — CoreStore-based persistent storage with versioned schemas (V1, V2)
  - `Strings/Strings.swift` — Auto-generated by SwiftGen from `Translations/en.lproj`
- **`Swiftfin/`** — iOS app: views, app entry point, iOS-specific components
- **`Swiftfin tvOS/`** — tvOS app: same structure as iOS but tvOS-specific views

Views for the same screen often exist in both `Swiftfin/Views/` and `Swiftfin tvOS/Views/` sharing the same ViewModel from `Shared/ViewModels/`.

## Key Libraries

- **Factory** — Dependency injection (`@Injected(\.service)`)
- **JellyfinAPI** (jellyfin-sdk-swift) — Jellyfin server API client
- **Defaults** — UserDefaults wrapper for app settings
- **VLCUI** — SwiftUI wrapper around VLCKit for video playback
- **Nuke** — Image loading/caching
- **Pulse** — Network logging
- **CoreStore** — Core Data wrapper for persistent storage
- **CollectionHStack/CollectionVGrid** — Custom collection layout views

## Code Style

- SwiftFormat config in `.swiftformat` (v0.54.6, Swift 5.6 compat)
- Max line width: 140 chars
- `// MARK:` comments for code organization (encouraged by project)
- MPL 2.0 license header auto-inserted by SwiftFormat
- `Shared/Strings/Strings.swift` is auto-generated — do not edit manually
- All user-facing strings must be localized (via `Translations/en.lproj`)
- Both iOS and tvOS builds must pass for PRs
